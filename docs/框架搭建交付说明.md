## 框架搭建交付说明

### 一、负责文件

---

### 二、已完成的核心任务

#### 1. 摄像机系统（已完成）

- 鼠标滚轮缩放，三档视角：远景（zoom 1.2）、中景（zoom 3.2）、近景（zoom 40.0）
- 鼠标拖拽平移
- 左侧 HUD 按钮切换远景/中景/近景
- 切换视角时摄像机平滑过渡（ease_in_out_cubic 缓动）

#### 2. 贴图切换逻辑（已完成）

- **远景**：皇宫使用 `assets/palace_far.png`（红色占位图片），坊使用 `assets/fang_far.png`（橙色占位图片）
- **中景 / 近景**：皇宫使用 `assets/palace_near.png`（绿色占位图片），坊使用 `assets/fang_near.png`（蓝色占位图片）
- 切换视角时自动调用 `_update_fang_textures()` 更新所有建筑和坊节点的贴图
- 皇宫建筑（宫城/皇城/大明宫/兴庆宫）使用皇宫贴图，城门/市场等建筑不贴贴图
- 坊节点使用坊贴图，贴图不存在时使用默认土黄色绘制
- `building.gd` 已支持 `tex` 属性，可进行等距菱形贴图渲染

#### 3. NPC 交互面板（已完成）

- NPC 在中景/近景可见，近景（zoom_idx == 2）时可点击交互
- 近景中点击 NPC 人物，屏幕右侧弹出交互面板
- 面板底部三个按钮：**衣食住行**、**建筑与城市规划**、**历史**
- 点击按钮后向大语言模型发送对应话题请求，回答以打字动画逐字显示
- 回答内容自动匹配图鉴词条，解锁对应类别的内容
- 面板有独立的关闭按钮，点击面板外区域也可关闭

#### 4. EventBus 广播（已完成）

所有跨模块通信均通过 EventBus 信号实现，模块间不直接引用节点路径。

### 三、事件信号清单

| 信号名 | 触发时机 | 参数 | 所在文件 |
|--------|----------|------|----------|
| `view_mode_changed` | 切换远景/中景/近景 | `mode: String`（"far" / "mid" / "near"） | EventBus.gd |
| `building_selected` | 点中建筑或坊 | `building_id: String`, `data: Dictionary` | EventBus.gd |
| `building_deselected` | 取消选中建筑 | 无 | EventBus.gd |
| `npc_dialogue_started` | NPC 群聊开始（中/近景点击说话中的 NPC） | `group_id: int` | EventBus.gd |
| `npc_interaction_started` | NPC 交互面板打开（近景点击 NPC） | `group_id: int` | EventBus.gd |
| `npc_interaction_topic` | 玩家点击 NPC 面板的话题按钮 | `group_id: int`, `topic: String` | EventBus.gd |
| `npc_panel_closed` | NPC 交互面板关闭 | 无 | EventBus.gd |
| `time_of_day_changed` | 时间改变 | `hour: float` | EventBus.gd |
| `year_changed` | 年份跳转 | `year: int` | EventBus.gd |
| `codex_entry_collected` | 图鉴解锁新词条 | `category: String`, `keyword: String` | EventBus.gd |
| `chat_response` | LLM 返回结果（NetworkManager） | `content: String`, `error: String` | NetworkManager.gd |

### 四、新增函数清单（changan_map.gd）

| 函数 | 功能 |
|------|------|
| `_update_fang_textures()` | 根据当前视角切换皇宫/坊贴图 |
| `_close_npc_panel()` | 关闭 NPC 交互面板并广播信号 |
| `_select_npc(gi)` | 打开 NPC 交互面板 |
| `_on_npc_topic_click(idx)` | 处理话题按钮点击 |
| `_request_npc_topic(topic)` | 向 LLM 发送话题请求 |
| `_build_npc_topic_prompt(topic)` | 构建话题 prompt |
| `_detect_codex_for_category(cat, text)` | 按类别检测图鉴解锁 |
| `npc_panel_close_rect()` | 返回关闭按钮的屏幕区域 |
| `npc_topic_button_rect(i)` | 返回第 i 个话题按钮的屏幕区域 |
| `_update_npc_panel_typing(delta)` | NPC 面板打字动画更新 |
| `_any_npc_group_at(pos)` | 检测屏幕位置是否有可点击的 NPC |
