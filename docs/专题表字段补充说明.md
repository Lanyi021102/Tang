# 专题表字段补充说明

PR1 以 `实体表` 为主体；专题表不再转换关系，关系以 `关系表` 为唯一来源。

## 导出规则

`tools/export_knowledge_graph.py` 按专题表键列匹配既有实体，并将实体表没有的字段写入 `entities.json` 的 `properties` 对象。保留专题表原始字段名，避免在导入阶段丢失语义。

| 专题表 | 键列 | 主要补充字段 |
| --- | --- | --- |
| 坊功能表 | `fang_key` | 面积、主/次功能、功能依据、邻近道路/水渠/市场/宫殿、几何与定位精度 |
| 道路分级表 | `road_key` | 道路等级/类型/方向、起终点、连接城门、宽度与换算依据 |
| 水渠表 | `canal_key` | 水源、流向、经过区域/坊、供水范围与用途 |
| 城门表 | `gate_key` | 城门类型、所属区域、城墙方位、功能、通行数量、经纬度与争议说明 |
| 地形表 | `terrain_key` | 覆盖范围、高程、坡向、地貌描述 |
| 重要建筑与设施表 | `building_key` | 建筑类型、所属区域/坊、功能、关联道路/水渠、建造与废弃年代 |

坐标 `x/y` 仍单独导出为 `grid_x/grid_y`，不写入 `properties`。
