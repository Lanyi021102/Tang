# 知识图谱导入说明

## 数据链路

知识图谱联合总表是人工审核源文件，Godot 不直接读取 Excel。项目通过转换脚本生成游戏和 RAG 使用的 JSON：

```text
联合总表.xlsx
  → tools/export_knowledge_graph.py
  → data/generated/*.json
  → 人工复核
  → 同步正式游戏 JSON
```

脚本默认读取相邻知识图谱数据工程仓库中的当前总表，不修改 Excel。脚本输出到 `data/generated/`；通过校验和人工复核后，将对应生成结果同步到 `data/` 下的正式游戏文件。

## 运行方式

在 Tang 项目根目录执行：

```powershell
python tools/export_knowledge_graph.py
```

如果总表不在默认位置：

```powershell
python tools/export_knowledge_graph.py --source "完整的xlsx路径"
```

默认只导出审核通过或已发布的数据。仅在调试时使用：

```powershell
python tools/export_knowledge_graph.py --include-drafts
```

依赖 Python 3.10+ 和 `openpyxl`：

```powershell
python -m pip install openpyxl
```

## 生成文件

| 文件 | 用途 |
|---|---|
| `sources.json` | 文献、论文和其他资料来源 |
| `source_chunks.json` | 史料片段，供溯源和 RAG 检索 |
| `entities.json` | 完整通用实体 |
| `relations.json` | 去重后的知识图谱三元组 |
| `changan_points.json` | 有项目坐标且适合地图展示的实体 |
| `history_timeline.json` | 从大事记/历史事件工作表提取的时间轴 |
| `research_claims.json` | 完整保留“研究结论表”的审核通过记录 |
| `validation_report.json` | 数量、悬空引用和跳过记录报告 |
| `import_manifest.json` | Excel SHA-256、导出时间和工作表清单 |

## 数据准入规则

- 默认只导出 `审核通过`、`已审核`、`已发布` 或 `通过` 的实体和关系。
- 含“示例”或“待补”的记录不进入正式输出。
- 相同实体编号合并证据。
- 相同 `(起点, 关系类型, 终点)` 三元组合并证据。
- 关系端点不存在、证据片段不存在、片段来源不存在时，校验报告的 `ok` 为 `false`，脚本退出码为 2。
- 坐标优先识别 `项目坐标` 或 `project_coordinate`，其次识别成对的 `grid_x/grid_y`、`project_x/project_y`、`x/y`。

## 与 Godot 的衔接

当前正式游戏数据已经同步为：

- `data/changan_points.json`：108 个 `Fang` 实体的完整地图视图；
- `data/history_timeline.json`：29 个 `HistoricalEvent` 实体的完整时间轴视图；
- `data/research_claims.json`：97 条研究结论。

三份正式文件应与 `data/generated/` 中的对应文件保持一致。`kepu_kb.json` 和 `codex_kb.json` 暂时保留旧数据，因为联合总表的“科普内容表”和“科普依据关联”当前为空。

本阶段不修改主程维护的 `changan_map.gd`。Godot 若要直接使用新字段，应由主程在独立 PR 中完成读取逻辑衔接。

坐标验收仍需人工抽查宫城、皇城、大明宫、兴庆宫、东市、西市、朱雀门街和明德门等锚点。

## 正式文件同步与验收

重新导出后先检查：

1. `data/generated/validation_report.json` 的 `ok` 必须为 `true`；
2. `import_manifest.json` 的 `source_sha256` 必须对应当前联合总表；
3. 抽查实体、关系、时间轴和坐标；
4. 确认后再将三份派生文件同步到正式路径；
5. 不把 `data/temporary_draft_check/`、`tools/__pycache__/` 或 Godot 场景文件纳入知识图谱 PR。

当前验收基线为：47 个来源、355 个史料片段、1630 个实体、1950 条关系、108 个坊点、29 条时间轴和 97 条研究结论。
