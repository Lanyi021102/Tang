# 长安营造司：百坊城局 —— 运行说明

> 本说明覆盖：环境准备、导入/运行项目、配置 AI 接口、导出与打包 macOS 版本、常见问题。
> 引擎版本必须为 **Godot 4.7 stable**（`4.7.1.stable.official`），版本不一致会报兼容错误。

---

## 一、环境要求

| 工具 | 用途 | 获取 |
|------|------|------|
| Godot 4.7 | 游戏引擎 | https://godotengine.org/download |
| Git | 版本控制 | macOS 自带；其他平台 https://git-scm.com |
| （可选）Node.js | AI 辅助开发（godot_mcp 插件） | https://nodejs.org |

macOS 导出还需已安装对应版本的导出模板（见 §五）。

---

## 二、获取代码

```bash
git clone git@github.com:Lanyi021102/Tang.git
cd Tang
```

> 若未配置 SSH：`ssh-keygen -t ed25519 -C "你的邮箱"` → 复制 `~/.ssh/id_ed25519.pub` → GitHub → Settings → SSH and GPG keys → New SSH key。

---

## 三、导入并运行

1. 打开 **Godot 4.7** → **Import（导入）** → 选择项目根目录的 `project.godot`。
2. 首次导入后，Godot 会自动扫描并导入资源（含字体、贴图），等待完成。
3. 直接点击右上角 **运行（F5 / ▶）**，主场景为 `res://scenes/Start.tscn`（开始菜单）。

**运行链路**：开始菜单（点「进入长安」）→ 卷轴 → 舆图展开（IntroScene）→ 轻点继续 → 长安城地图。

---

## 四、配置 AI / LLM 接口（可选，影响群聊 AI 科普）

群聊 NPC 的 AI 讲解依赖 LLM 接口。若未配置，相关功能会请求失败。

1. 复制模板为真实配置：
   ```bash
   cp config/llm_config.json.example config/llm_config.json
   ```
2. 编辑 `config/llm_config.json`：
   - `api_key`：填入真实 Key。
   - `api_base_url`：供应商地址（默认 OpenAI 兼容接口 `https://ai.leihuo.netease.com/v1`）。
   - `model`：默认 `deepseek-v4-flash`。
3. 可选 RAG：如使用本地 RAG 服务，配置 `rag_base_url`（默认 `http://127.0.0.1:8080`）与 `rag_path`。

> `llm_config.json` 已在 `.gitignore` 中，不会提交；请勿把 Key 提交到仓库。

## 五、macOS 导出 / 打包

### 1. 安装导出模板（一次性）
下载 Godot 4.7.1 导出模板 `.tpz`，解压后把 `templates/*` 放入：
```
~/Library/Application Support/Godot/export_templates/4.7.1.stable/
```
（需含 `macos.zip` 与 `version.txt`。）

### 2. 导出为 .app / .zip
在项目根执行：
```bash
/Applications/Godot.app/Contents/MacOS/Godot --headless --export-release "macOS" ./build/长安营造司.zip
```
产物：
- `build/长安营造司.zip`（分发包，内含 `.app`）。
- 解压后可得到 `长安营造司：百坊城局.app`，双击运行。

> ⚠️ 若提示「禁用 ETC2 ASTC 时无法为 universal/arm64 导出」，请在 `project.godot` 的 `[rendering]` 下确保 `textures/vram_compression/import_etc2_astc=true`（本仓库已配好）。

### 3. 签名说明
- 当前产物为 **ad-hoc 临时签名**，本机可直接运行；`codesign --verify --deep` 通过。
- 发给**其他** Mac：首次打开可能被 Gatekeeper 拦截 → **右键 → 打开**。
- 正式分发/上架：需 Apple 开发者证书签名 + 公证（notarization）。

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 打开项目报版本不兼容 | 安装 Godot `4.7`（非其他版本），重新导入项目 |
| 中文字体乱码 | 确认 `assets/fonts/` 下字体已导入；本项目已用 `FontKit` 打包字体，拉取最新代码即可 |
| 群聊 AI 无回复 | 检查 `config/llm_config.json` 的 `api_key`/`api_base_url` 是否正确配置 |
| 导出 arm64 失败 | 开启 `import_etc2_astc`（见 §五·2） |
| 导出模板缺失 | 按 §五·1 安装对应版本模板 |
