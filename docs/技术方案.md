# 长安营造司：百坊城局 —— 技术方案文档

> 唐长安城知识图谱科普项目。基于 Godot 4.7（Mobile 渲染器 + Jolt Physics）开发的 2.5D 等距地图 + 知识科普玩法。
> 文档目的：说明项目技术架构、模块职责、数据流与关键实现，便于协作与维护。

---

## 1. 项目概览

| 项 | 值 |
|----|----|
| 引擎 | Godot 4.7 stable（标准版，非 .NET；本机实测 `4.7.1.stable.official`） |
| 渲染器 | Mobile（`renderer/rendering_method="mobile"`） |
| 物理 | Jolt Physics |
| 主场景 | `res://scenes/Start.tscn`（开始菜单） |
| 游戏名 | `长安营造司：百坊城局` |
| 视口 | 1920 × 1080，`canvas_items` 拉伸 + `expand` 宽高比 |

**玩法链路**：开始菜单 → 卷轴动效 → 舆图展开（IntroScene）→ 轻点继续 → 长安城地图（ChangAnCity），在海量坊/街/皇城的可缩放等距地图上点击实体查看知识卡片、大事记、图鉴，并通过群聊 NPC 触发 AI 科普讲解。

## 3. 场景与流程

| 场景 | 文件 | 作用 |
|------|------|------|
| 开始菜单 | `scenes/Start.tscn` → `opening_ui.gd` | 水墨山水首页，菜单按钮、视差、行走人物；点击「进入长安」触发卷轴 |
| 舆图展开 | `scenes/IntroScene.tscn` → `intro_scene.gd` | 独立的转场场景：卷轴滚入 →「舆图展开 · 入司理事」+ 轻点继续 |
| 长安城 | `scenes/ChangAnCity.tscn` → `changan_map.gd` | 主玩法：2.5D 等距可缩放地图、命中、知识卡、大事记、图鉴、群聊 |
| 主菜单(备用) | `scenes/MainMenu.tscn` → `main_menu.gd` | 历史遗留第二菜单（当前流程未使用） |
| 旧地图 | `scenes/ChangAnMap.tscn` | 历史遗留场景 |

**进入链路（三场景流程）**：

1. `opening_ui.gd` 点击「进入长安」→ `_scroll_t` 驱动自左向右的墨色卷帘盖过菜单（无黑屏，露出「舆图展开 · 入司理事」）。
2. 卷帘盖满后 `change_scene_to_file(IntroScene.tscn)` → `intro_scene.gd` 以「已覆盖」状态呈现舆图展开 + 轻点继续。
3. 点击轻点继续 → `SceneTransition.goto_scene_intro()`：`scene_curtain.gd` 卷帘盖住 → 加载 `ChangAnCity`（场景 3，地图在帘后构建）→ 加载完成后卷帘滚出揭示地图。**全程无缝、无灰屏/黑屏穿帮，进入与退出使用同一套卷轴动效。**

> 入口与卷帘配色统一为深青绿墨色（`#0a1512`），与舆图展开、卷轴颜色一致，保证衔接。

## 5. 数据层（DataManager）

`DataManager._ready → load_all()` 从 `res://data/` 读入：

| 数据 | 文件 | 用途 |
|------|------|------|
| `points` | `changan_points.json` | 地图实体/命中点 |
| `kepu_kb` | `kepu_kb.json` | 科普知识库（群聊 AI 讲解触发/回答） |
| `codex_kb` | `codex_kb.json` | 图鉴条目库 |
| `knowledge_cards` | `knowledge_cards.json` | 知识卡片数据（正面/背面字段） |
| `timeline` | `history_timeline.json` | 长安城大事记（年份/标题/详情） |
| `llm_config` | `res://config/llm_config.json` | LLM/RAG 接口配置（见 §6） |

> `llm_config.json` 被 gitignore，仓库仅保留 `llm_config.json.example` 模板；运行前需拷贝配置真实 API Key。

## 6. AI / LLM 网络层（NetworkManager）

- 配置来源：`config/llm_config.json`。
- 供应商：**OpenAI 兼容接口**（`https://ai.leihuo.netease.com/v1`），`chat/completions`；模型 `deepseek-v4-flash`。
- 关键字段：`api_key`、`model`、`temperature`、`max_tokens`、`system_prompt`；RAG：`rag_base_url`(`http://127.0.0.1:8080`) + `/api/v1/ai/game-chat`。
- 信号：
  - `chat_response(content, error)`（旧场景兼容）
  - `chat_completed(request_id, content, metadata)`、`chat_failed(request_id, error)`、`request_state_changed(...)`（新调用）
- 方法：`request_chat(...)`、`request_chat_with_id(...)`、`request_rag(...)`、`cancel_request(...)`；`has_api_key()` 检测占位 key。
- `system_prompt` 约束 AI 为「知识图谱科普讲解员」，仅基于知识库字段作答，区分史料记载与学者推测。

## 7. 字体与资源一致性（FontKit）

> 保证跨平台（不同电脑）中文/英文渲染完全一致，避免系统字体缺失导致乱码。

- `scenes/font_kit.gd`（`class_name FontKit`）提供：
  - `latin()` / `latin_bold()`：打包的 Times New Roman（`assets/fonts/times-new-roman.ttf`）。
  - `cjk()`：打包的 qiji-fallback（`assets/fonts/qiji-fallback.ttf`，38MB，含 2 万余 CJK 字形，无拉丁）。
  - `composite()` / `composite_bold()`：以 Times 为 base、`fallbacks=[cjk]`，实现「英文/数字 Times、中文 qiji」。
- **加载方式**：优先 `ResourceLoader.load()` 取导入后的 `FontFile`（导出包内可用、含中文字形），`load_dynamic_font()` 仅兜底。
- 应用：`changan_map`、`opening_ui`、`intro_scene`、`main_menu`、`start` 均改用 `FontKit`。

## 8. 绘制 / 渲染管线（changan_map + ui_overlay + clip_list）

- **`changan_map.gd`**：Node2D 主逻辑。构建等距坊/街/皇城节点（`fang_tile`/`street_tile`/`huangcheng_tile`/`world`），相机缩放（远景/中景/近景三档 + 滚轮细腻缩放），命中检测 `_handle_click`，以及时间/时辰、天气光照（`_update_lighting`）、倾斜移轴（`_update_tilt_shift`）等。
- **`ui_overlay.gd`**：Overlay 控制层，逻辑画布 1280×720，整体 scale 铺满视口。负责：屏幕墨晕、左侧功能栏、右上时钟（表盘+长短针）、底部时间轴、大事记面板、图鉴面板、知识卡（正/反面翻转）、群聊气泡、技能提示等。
- **`clip_list.gd`**：裁剪容器，处理大事记列表（含绿色细节框逐字揭示）、图鉴知识卡轮播（拖拽/滚轮/焦点）、时空关系卡。
- **非线性动画约定**：面板开关、时间轴收起、时辰弹窗等均使用 `_ease_in_out_cubic` 插值；门帘/卷轴用 `smoothstep`（`x*x*(3-2x)`）。

## 9. 导出 / 部署（macOS）

- 预设：`export_presets.cfg` → macOS，`universal`（Intel + Apple Silicon），`import_etc2_astc=true`（universal/arm64 必开，位于 project.godot `[rendering]`）。
- 打包字体（`assets/fonts/*.ttf`）随 `export_filter="all_resources"` 进入 pck；`FontKit` 用 `ResourceLoader.load` 取回。
- 产物：`.app`（ad-hoc 签名，`codesign --verify` 通过，本机可运行）+ `.zip` 分发包；正式分发需 Apple 开发者证书 + notarization。
- 导出命令：
  ```bash
  /Applications/Godot.app/Contents/MacOS/Godot --headless --export-release "macOS" ./build/长安营造司.zip
  ```
- 导出模板位置：`~/Library/Application Support/Godot/export_templates/4.7.1.stable/`。
